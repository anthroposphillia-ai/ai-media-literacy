# AI 미디어 리터러시 — AI 기사를 판정하는 8원칙

AI를 소재로 한 기사를 읽을 때, **무엇이 사실이고 무엇이 프레이밍인지** 가르는 판정 기준을 정리한 책입니다. 원칙을 선언하는 데서 멈추지 않고, 실제 기사 문장을 인용해 **어디가 틀렸고 어떻게 고쳐 쓰는지**까지 보여줍니다.

## 이 책이 답하는 질문

- "AI가 ~했다"는 제목을 어디까지 믿어야 하는가
- 벤치마크 숫자·통계가 실린 기사에서 무엇을 더 확인해야 하는가
- "업계 관계자에 따르면"이 사실과 어떻게 다른가
- 같은 사건을 다룬 기사 중 어느 쪽이 정확한지 어떻게 판단하는가
- 직접 비평 글을 쓰려면 어떤 절차를 따라야 하는가

## 판정 기준 — 8원칙

| 원칙 | 한 줄 |
|---|---|
| ③ 기술적 한계 공개 | 과제·비교집합·조건·데이터 범위를 함께 밝힌다 |
| ⑤ 이해관계 공개 | '주장'과 '사실'을 구분한다 |
| ⑦ 검증 가능한 출처 공개 | 기관·날짜·보고서명·링크 |
| ④ 맥락 제시 | 수치를 미래 전체로 부풀리지 않는다 |
| ⑧ 대안·선택지 제시 | 결정론 대신 사회적 선택 |
| ⑥ 비용과 편익 동시 제시 | 무엇을 얻고 무엇을 치렀나 |
| ① 의인화 금지 | AI를 인간 행위자로 만들지 않는다 |
| ② 책임 주체 명시 | 도입·운영을 결정한 사람을 밝힌다 |

장 순서는 **실측 빈도순**입니다. 2026년 10월 9일~17일, 9일간 AI 관련 기사 비평 22회차에서 위반을 지목한 횟수를 세면 ③ 29회(27%), ⑤ 22회(21%), ⑦ 19회(18%), ④ 18회(17%), ⑧ 14회(13%), ⑥ 12회(11%), ① 8회(7%), ② 8회(7%) 순이었습니다. 독자가 실제로 가장 자주 만나는 함정부터 다룹니다.

①·②는 개념적으로 이 책의 토대입니다(사람이 사라지면 나머지 원칙이 성립하지 않습니다). 실측 빈도가 가장 낮아 마지막 두 장에 배치했지만, 먼저 읽고 싶다면 01-7장부터 보셔도 됩니다.

## 읽는 순서

- **일반 시민**: 01부(8원칙) → 각 장 끝 "그래서 당신은 · 시민이면" → 8원칙 체크리스트(01-9)를 인쇄해 두고 기사 볼 때 사용
- **교사·교육자**: 03부 판정 훈련(12세트) → 1단계 체크표만 인쇄해 배포 → 해설로 대조
- **미디어·정책 종사자**: 01부 → 검증 절차와 사례 카드 → 직접 만들기(수집·채점·발행 파이프라인)

## 집필 현황과 한계

- **01부(판정의 기준 — 8원칙)**: 완성 (2026-10-17)
- **02부(사건 해부 — 한 사건, 여러 원칙)**: 완성 — 검증 카드 27장을 **11개 사건**으로 묶어 원문이 지운 것·바로잡은 문장·검증 출처를 함께 실었습니다 (2026-10-17)
- **03부(판정 훈련 — 기사 한 편에 8원칙)**: 완성 — **12세트**. 스스로 판정 → 해설 → 자기 채점 3단계로 구성, 수업 활동지로 바로 사용할 수 있습니다 (2026-10-17)
- 04부 직접 만들기 / 05부 한계·오판: 순차 추가
- 사례 인용은 **제목과 문제 문장의 짧은 인용 + 원문 링크**로 제한했습니다(전문 전재 없음). 이미지는 쓰지 않았습니다.
- 사례는 시효가 있습니다. 카드마다 날짜를 밝혔고, 보도 이후 정정이 나온 사건은 정정 내용까지 함께 적었습니다. 연 1회 개정을 전제로 합니다.
- 이 책은 언론사나 특정 매체를 비난하려는 것이 아닙니다. **문장 단위의 판정 훈련**이 목적이며, 잘못을 지적한 기사에도 정확한 부분이 있으면 함께 밝힙니다.
