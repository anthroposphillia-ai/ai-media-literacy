## ② 채점 — 8원칙으로 위반을 센다

### 채점표

기사 한 편을 읽고 아래 8항목을 **O/X로 빠르게** 표시합니다. X가 많을수록 좋은 판정 대상입니다.

| 원칙 | X를 줄 때 (한 줄 판정) |
|---|---|
| ① 의인화 | AI가 주어이고 의도 동사(해킹·거짓말·결정·해고)를 씀 |
| ② 책임 주체 | 책임 주체가 없거나 "시스템·알고리즘"으로 표기 |
| ③ 기술적 한계 | 과제·비교집합·조건·데이터 범위 중 하나라도 빠짐 |
| ④ 맥락 | 분모 없음 / 비교 대상 없음 / 전체로 확대 |
| ⑤ 이해관계 | "관계자에 따르면" / 자기 보고서를 논문처럼 / 출처 없는 통계 |
| ⑥ 비용·편익 | 한쪽만 있음(편익만 또는 비용만) |
| ⑦ 출처 | 원문 링크 없음 / 링크가 기사와 다른 말을 함 |
| ⑧ 대안·선택지 | "막을 수 없다"류 결정론 / 유보·거부 사례 없음 |

### 점수화와 순위

```
점수 = 지목한 원칙 개수 (복수 지목 포함)
1순위 = 최악(가장 많이 어긴 기사)
2순위 = 두 번째(같은 회차에 함께 다룰 기사)
```

실제 기록에서 나온 분포는 이렇습니다(22회차, 지목 563회).

| 원칙 | 비중 | 함의 |
|---|---|---|
| ③ 기술적 한계 | 27% | **가장 흔한 실패** — 숫자와 조건 분리 |
| ⑤ 이해관계 | 21% | 출처 등급이 사라진다 |
| ⑦ 출처 | 18% | 링크·성격 표기 실패 |
| ④ 맥락 | 17% | 분모·범위 삭제 |
| ⑧ 대안 | 13% | 결정론 |
| ⑥ 비용·편익 | 11% | 한쪽만 |
| ① 의인화 / ② 책임 | 7% / 7% | 빈도는 낮지만 **개념적 토대** |

### 운영 규칙

- **지목은 문장 단위로** — 기사 전체가 아니라 문장 하나를 잡고 원칙 번호를 붙입니다(예: `③⑦`).
- **한 회차 2건까지** — 1순위만 쓰면 그날의 비교가 사라집니다. 2순위를 함께 두면 "같은 사안을 다르게 쓴 두 기사"를 비교할 수 있습니다.
- **점수만으로 결정하지 않는다** — 점수가 같으면 **원문 접근이 가능한 쪽**을 고릅니다(⑤⑦을 우리가 지킬 수 있는 쪽).
- **편향 보정** — 이 방식은 실패 사례만 모읍니다. **분기마다 정확한 보도 1건**을 골라 "이 기사는 왜 정확한가"를 함께 남기세요(05-4의 편향 대응).
