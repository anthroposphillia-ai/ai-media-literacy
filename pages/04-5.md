## ⑤ 검증·정정 — 우리가 지킨 규칙

### 검증 4관문 (집필 전)

| 관문 | 확인 | 통과 기준 |
|---|---|---|
| 1. 인용 | 지적할 문장이 실제로 있는가 | 검색으로 실재 확인 |
| 2. 원문 | 원문(외국 보도·보고서)을 확보했는가 | 확보 못 하면 **그 사례는 버림** |
| 3. 출처 등급 | 1차 문서 / 공식 발표 / 자기 보고서 / 익명 / 없음 | 등급을 명시 |
| 4. 교정 | 대체 문장을 썼는가 | 못 쓰면 발행 보류 |

### 발행 후 모니터링

익명 소식통 기사는 **반박이 나올 확률이 가장 높습니다**(05-2의 1번 사건). 익명 소식통을 인용한 글은 **24시간 안에 후속 보도를 확인**하세요.

| 신호 | 조치 |
|---|---|
| 보도가 정정·반박됨 | 카드에 `[정정]` 항목 추가 + 교정 문장 갱신 |
| 원문 링크가 죽음 | 링크 교체, 안 되면 카드 은퇴 |
| 우리 판정이 틀렸음 | **글 상단에 정정 표시**를 달고 수정 이력 남기기 |

### 정정 양식

```
[정정 2026-10-17] 10월 14일 보도에 근거해 작성한 카드의 내용을 수정했습니다.
이후 방송사는 "AI 에이전트가 스스로 행동한 것이 아니다"라고 부인했고,
조사 결과 원인은 제작사의 인적 요인(백업 실패)으로 정리됐습니다. 교정 문장을 갱신했습니다.
```

### 사례 카드 양식 (최종)

```
[날짜] [매체] [기사 제목] [어긴 원칙 번호]
① 문제 문장 — 원문 그대로
② 무엇이 문제인가 — 원칙별로 한 줄씩
③ 바로잡은 문장 — 대체 문장
④ 출처 등급 — 1차/공식/자기 보고서/익명
⑤ 원문 링크
⑥ [정정] — 이후 반박·정정이 있으면 날짜와 함께
```

이 양식이 이 책 02부의 카드이고, 03부의 해설이고, 앞으로 여러분의 축적물이 됩니다. **8원칙 번호로 태깅된 카드**를 100장쯤 모으면, 어떤 원칙이 가장 자주 깨지는지가 데이터로 보입니다 — 이 책을 쓰게 만든 것이 그 숫자였습니다.
