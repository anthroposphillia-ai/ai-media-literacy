## 8원칙 판정 체크리스트

기사를 읽으면서 아래 순서대로 씁니다. **인쇄해서 옆에 두고 쓰시면 됩니다.** 판정은 3단계입니다.

### 판정 3단계

1. **문장을 그대로 옮겨 적는다** — 요약하지 않습니다. 요약하는 순간 판정이 흐려집니다.
2. **어긴 원칙 번호를 붙인다** — 한 문장이 여러 원칙을 어기는 것이 보통입니다(예: `①③`).
3. **바로잡은 문장을 쓴다** — 대체 문장을 쓰지 못하면 아직 판정이 아닙니다.

### 8원칙 체크리스트

| 원칙 | 물어야 할 것 | 체크 |
|---|---|---|
| **③ 기술적 한계** | 과제·비교집합·조건·데이터 범위가 다 있는가? 같은 벤치마크 다른 표에서도 같은 순위인가? | □ |
| **⑤ 이해관계** | "A가 말했다"인가 "A가 그랬다"인가? 말한 사람은 무엇을 얻나? 출처 없는 통계는 없는가? | □ |
| **⑦ 출처** | 원문 링크가 있고, 열면 같은 말을 하는가? 공식/익명/자기 보고서 중 무엇인가? | □ |
| **④ 맥락** | 분모는? 비교 대상은? 어디까지 확대해도 되는가? | □ |
| **⑧ 대안·선택지** | 누가 결정했나? 유보·거부 사례가 있는가? 독자가 할 수 있는 일이 한 줄이라도 있나? | □ |
| **⑥ 비용과 편익** | 비용 주체가 있나? 새로 생긴 위험이 있나? 편익이 배수로만 있나? | □ |
| **① 의인화** | 주어가 AI인가 사람인가? 동사가 의도를 부여하나? | □ |
| **② 책임 주체** | 이름·직위로 나오나? 여러 갈래가 한 갈래로 접히지 않았나? | □ |

### 위험 신호 12개 (제목·리드에서 먼저 확인)

1. "AI가 ~했다" — 의도 동사
2. "세계 최초 · 압도적 · 초인적" — 비교 조건 없음
3. "업계 관계자에 따르면" — 익명 승격
4. "설문에 따르면" (기관·표본 없음) — 출처 없음
5. "%"만 있고 분모 없음
6. "막을 수 없다 · 이미 시작됐다 · 궤도에 진입" — 결정론
7. "AI로 인한 해고" — 회사가 인정한 적 있는지 확인
8. 회사 보도자료와 문장이 거의 동일 — 보도자료 전재
9. "~할 수 있다"와 "~했다" 혼용
10. 원문 링크 없음
11. 외국 원문에는 있는 유보 문장이 빠짐
12. 책임 주체가 "시스템 · 알고리즘"으로 표기

### 점수 기록 (한 편 기준)

| 항목 | 기록 |
|---|---|
| 기사 제목 / 매체 / 날짜 | |
| 어긴 원칙 (번호) | |
| 그대로 옮긴 문제 문장 | |
| 바로잡은 문장 | |
| 원문 링크 | |

### 판정 강도

| 어긴 원칙 수 | 판정 |
|---|---|
| 0~1 | 정확한 기사 — 그대로 인용 가능 |
| 2~3 | 부분 수정 — 인용 시 조건을 함께 밝힐 것 |
| 4 이상 | 사용 보류 — 원문을 직접 확인할 것 |

> 마지막 규칙 하나. **지적한 기사에도 정확한 부분이 있습니다.** 그 부분을 함께 적지 않으면, 판정은 비평이 아니라 공격으로 읽힙니다. 이 책이 모든 사례에 "무엇이 문제인가"와 "바로잡으면"을 나란히 둔 이유입니다.
